
# Traffic Management Dashboard

## Project Description
A web-based Traffic Management Dashboard to monitor traffic conditions and vehicle counts.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Total vehicle count
- Active routes
- Traffic status
- High, Medium and Low traffic levels
- Refresh traffic data

## How to Run
1. Download the project.
2. Open index.html in a browser.
3. View the traffic dashboard.
4. Click Refresh Traffic to update sample data.

## Note
This project uses sample traffic data for demonstration.
It does not display real-time traffic information.
