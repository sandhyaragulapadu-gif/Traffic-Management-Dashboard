
# 🚦 Smart Traffic Management Dashboard

## Project Description
Smart Traffic Management Dashboard is a web-based application designed to monitor traffic conditions and display vehicle information.

It provides Demo Mode with automatically updating traffic data and a Live Mode option for future real-world traffic API integration.

## Features
- Automatic Vehicle Count Updates
- Traffic Route Monitoring
- Traffic Signal Status
- Road Congestion Detection
- Traffic Alerts
- Demo Mode
- Live API Integration Support
- Responsive Dashboard

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Modules
1. Dashboard Overview
2. Vehicle Monitoring
3. Traffic Route Details
4. Traffic Signal Monitoring
5. Congestion Alerts
6. Demo and Live Modes

## How to Run
1. Download or clone the repository.
2. Open index.html in a browser.
3. Select Demo Mode.
4. Monitor automatically updating traffic data.
